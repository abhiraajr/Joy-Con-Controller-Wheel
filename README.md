# Joy-Con Controller Wheel

A steering wheel for Nintendo Joy-Con controllers that I designed myself in 3D, shown in an interactive in-browser viewer built on the same code as [Orbit3D](https://github.com/abhiraajr/Orbit3D).

## What's in here
| File | What it is |
|---|---|
| `Built Joy-Con Controller Wheel.obj` + `.mtl` | The assembled wheel |
| `Joy-Con Controller Wheel Parts.obj` + `.mtl` | The individual parts, laid out separately |
| `index.html` | The viewer page with a menu to switch between the built and parts views |

## Status
Design only. The models are mine, but I haven't recorded whether the wheel was 3D printed and tested, so this repo doesn't claim that.
